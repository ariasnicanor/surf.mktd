# Surf Marketing Launchpad

Quiero que diseñes y desarrolles una landing page moderna, minimalista y profesional para una agencia de marketing llamada “Surf Marketing”.

La landing debe transmitir confianza, profesionalismo, creatividad y cercanía. El diseño debe ser limpio, visual y responsive tanto para desktop como mobile.

ESTILO VISUAL:

Diseño moderno y minimalista

Estética premium pero simple

Uso de espacios amplios

Animaciones suaves al hacer scroll

Tipografía moderna y elegante

Secciones bien diferenciadas

Priorizar conversión y contacto

Colores basados en la identidad de Surf Marketing (voy a subir el logo luego)

Botones modernos con hover effects

Diseño muy visual y dinámico

ESTRUCTURA DE LA LANDING:

HEADER / NAVBAR
Navbar fija y simple con:

Herramientas

Contacto

“Solicitar presupuesto”
